# PHASE — вычислительная архитектура обратимой фазы

> Версия 0.1 · Синтез: парадигма (манифест 20 проектов) × опыт прошлых систем
> (SINT-UA, DSO/DSO-TRON, MPTC, DSA, DSO Control, mime-os) × измеренные факты
> (phase-vm POC-1: откат O(шагов), арена O(1)-rollback, PC1 decrypt=reverse).
>
> Цель документа — не список проектов, а **одна архитектура**, в которую эти
> идеи складываются слоями с проверяемыми инвариантами.

---

## 0. Тезис

Фон-неймановская машина трактует время как **деструктивную однонаправленную
координату**: `a = b + c` стирает `a`, откат требует внешних снапшотов/логов,
память пассивна, ошибка лечится перезапуском. PHASE меняет дисциплину, а не
транзисторы:

> **Вычисление — это движение фазового состояния. Внутри фазы все операторы
> биективны (время проходимо в обе стороны, откат бесплатен). Стирание, вход
> и выход существуют только на границах фаз и оплачиваются там явно.
> Решение commit/rollback принимает валидатор на границе. Детерминизм
> запечатан hash-цепочкой. Состояние переносится капсулами (.eml/.vcf).**

Архитектура — ансамбль фаз: фаза = минимальная единица вычисления, хранения,
коммуникации и отказа.

Три независимые оси (не смешивать — это разные выигрыши):

| ось | что даёт | источник |
|---|---|---|
| **A. Обратимость** | энергия стирания + бесплатный откат O(шагов) | Ландауэр-61, Беннетт-73, Фредкин-Тоффоли-82 |
| **B. Meet-in-the-middle** | sqrt-фактор в поиске с декомпозицией | крипто-атаки, двунаправленный BFS |
| **C. Дисциплина границ** | топология/память/коммуникация/отказ | опыт MPTC, DSO, mime-os |

## 1. Аксиомы (что мы проверили и что честно)

1. **Обратимость живёт на битах/целых.** IEEE-754 необратим (NaN, округление).
   Фазовая риторика — только на целочисленных операторах. (измерено/решено)
2. **«Без логов» — внутри фазы.** Источник инструкции *есть* лог: оператор
   модифицирует один destination, источники целы и достаточны для инверсии →
   `F⁻¹(F(X)) = X` из текущего состояния, 0 байт. (phase-vm: fuzz 5000/5000)
3. **Стирание = граничное bulk-событие.** `set`/`mset`, I/O, внешний вход —
   единственные необратимости; платятся один раз на границе. (mp-модель)
4. **Откат стоит O(шагов), не O(байт).** reverse ~6.8 ns/лист при состоянии
   64 B → 1 MB; снапшот растёт с состоянием (до 25 µs @ 1 MB). (измерено)
5. **Память фазы: O(1)-rollback-арена.** bump = обратимая аллокация,
   rollback-to-mark = один truncate; ноль per-object заголовков; память =
   пик фазы, не сумма. Выигрыш только на phase-shaped жизнях. (измерено:
   4–20× против malloc/free на тик/транзакция/ECS; на случайных жизнях — нет)
6. **Валидация после применения.** Инварианты, видимые только после apply
   (каскады, производные состояния), — главный кейс rollback. Хост решает
   commit/abort; машина остаётся чисто обратимой. (batch_tx: 35.8% abort,
   spec_control: 300k тиков)
7. **Детерминизм + hash-chain = аудит.** Тот же вход → та же траектория
   бит-в-бит; цепочка границ фаз доказывает идентичность прогонов. (SINT:
   «hash-chain дёшев и окупается»)
8. **Data-dependent ветвление честно стоит журнала решений** — O(решений),
   не O(состояния). Это следующий слой L3, не нарушение аксиомы 2.
9. **Где НЕ выигрываем:** сырая пропускная способность арифметики; общая куча
   с долгоживущими случайными жизнями; float; произвольный ввод-вывод.
   Архитектура это не обещает — это её границы.

├─────────────────────────────────────────────────────────────┤
│ L0  БИЕКТИВНОЕ ЯДРО (op-set на u64)                          │
│     add↔sub, xor, rot, toff, cswp, madd/msub...              │
│     инвариант: один destination, источники целы              │

    ── ось B (MITM-сервис поиска) ──  ── телеграф/аудит (#17) ──

### L0 — Биективное ядро
Набор операторов, у каждого из которых есть обратный, вычислимый из текущего
состояния. **Инвариант:** оператор биективен на словах `u64`; алиасинг
операндов (`dst==src`, `target==control`) запрещён статически.
Варианты кодирования: тройка (ternary-vm), обратимые CA (CellularDataflow) — pluggable. Статус: **готово** (phase-vm ISA: `nop not inc dec xor add sub swp rotl rotr
toff cswp` + память `madd msub mxor rmadd rmsub`; границы `set mset`).

### L1 — Фазовая машина
Фаза = запуск обратимого ядра между границами. Граница = точка, где
происходит вход (данные/возмущения), выход (результат) или стирание (сброс).
`rep` = статический цикл-фаза (повтор биекции N раз; обратный — N инверсий).
Верификатор классифицирует каждый лист: обратимый / граница / нарушение.
**Инвариант:** внутри фазы `F⁻¹∘F = Id`; пересечение границы — явная,
измеряемая операция.
Статус: **готово** (phase-vm: run/runrev/rev/roundtrip/dbg; check).

### L2 — Память фаз (арены)
Аллокация = сдвиг границы (обратимая операция). `rollback(mark)` = truncate.
Ноль метаданных на объект. Коммит-режим платит один `reset` на границе.
Per-thread арены; передача владения между фазами — капсулами, не «free».
SoA-лейны (урок DSA): данные одной фазы лежат однородно, векторно.
**Инвариант:** пик фазы, не сумма; жизни объектов вложены в фазу.
Статус: **готово ядро** (src/alloc.rs, замеры в examples/alloc_bench.rs);
нет per-thread и интеграции с L3.

### L3 — Семантика и управление
- **Транзакция = пачка** обратимых операций + host-валидатор на границе.
  Abort = обратный прогон пачки. (batch_tx — работает). Валидаторы на границах несут quorum/trust-семантику SINT: решение commit принимает *не* исполнитель фазы, а внешний quorum — урок «агент не верифицирует сам себя».
- **Тик = фаза; кандидат = спекуляция.** Несколько кандидатов применяются,
  валидируются, отвергнутые откатываются; лучший коммитится. (spec_control)
- **Ensemble-лейны:** E вариантов растения живут в одном состоянии; кандидат
  принимается, только если инвариант держится на всех лейнах (урок DSO
  Control: worst-case, не номинал). (ensemble_control)
- **Decision-журнал** (готово, phase-vm v0.1.4): `ifnz/wz/rep`, журнал
  O(решений); 500k-итераций while = 1 запись; fuzz F⁻¹∘F==Id на случайных
  структурированных программах.
- **Hash-chain аудит** границ: цепочка состояния = нестираемый журнал,
  проверка детерминизма и реконсиляции. (State::hash/chain_step — готово)
**Инвариант:** журнал — только решения, никогда состояние.

### L4 — Капсулы (.eml/.vcf)
Единица переноса фазы между машинами/процессами/хостами (идея манифеста,
субстрат mime-os). `.vcf` = манифест актора/фазы: фазовые инварианты, порты,
права/ключи, реестры (SINT). `.eml` = контейнер: заголовки = метаданные
инвариантов, тело = траектория/журнал решений, MIME-аттачи = срезы состояния,
запечатано hash-цепочкой.
**Инвариант:** капсула самодостаточна и проверяема без исходной машины.
Статус: дизайн; субстрат существует (mime-os клетки, marketplace .eml-спул). Заголовки капсулы несут семантический регистр (SENSE/FACT/…) — провенанс мысли переезжает вместе с состоянием.

### L5 — Приложения на фазах
- **тик = фаза** (DSO/MPTC): детерминированные симуляции, ECS, серверы —
  rollback-реконсиляция вместо снапшотов (**netcode-демо готово**, phase-vm v0.1.5:
  142k реконсиляций, журнал входов 16× легче снапшотов, hash-сверка с эталоном);
- **агент-шаг = фаза** (SINT): recovery-протокол становится механическим —
  провал шага = rollback к последнему верифицированному состоянию;
  регистры/quorum/trust решаются на границах, не внутри;
- **ансамбль/worst-case** (DSO Control) — L3 поверх;
- **PC1** (#12): decrypt = обратный прогон, нет ветвлений по данным;
- **автоинженер**: forward-генерация + обратная волна ошибок компилятора
  стягивается к AST-узлу; «встреча» = зелёная сборка/тест (ось B + L1).

### Оси через слои
- **B · MITM-сервис**: поиск с sqrt-гарантией (двунаправленный BFS/планиро-
  вание/синтез обратимых программ из опыта x86_superopt). Честные условия:
  декомпозиция `f=h∘g`, дешёвая проверка встречи. **Не тронута — строить.**
- **Телеграф (#17)**: hash-цепочки границ как метрика; бифуркация = скачок
  drift-метрики (историограф). 1–3 инварианта, не «64-мерный фазовый поток».

## 3. Пазл прошлых систем — куски целого

PHASE не «рядом с» прошлыми проектами: она **впитывает** их. Каждая система —
кусок пазла, вносящий либо готовый субстрат, либо направление. Репозитории —
не обязательство, важна идея и слот.

| Система | Идея-кусок | Слот в PHASE |
|---|---|---|
| **SINT-UA v2 + sint-\* MCP** (epistemic, liquid, prospective, resonance, dream, swarm, self, marketplace) | семантические регистры SENSE/FACT/LOGIC/OPINION/CAUSALITY; quorum/trust; hash-chain; ревизия убеждений; роевые голосования | регистры и quorum/trust = валидаторы **на границах L5**; hash-chain = аудит L3; liquid/epistemic = слой убеждений над фазами; capsule = носитель регистров L4 |
| **SINT v3 / KCC** (ACT-R/SOAR/LIDA: chunking, activation, global workspace, impasse) | когнитивный рантайм; продукция = шаг; **impasse = граница** → разрешение = откат + решение | L5 когнитивный слой: продукция-фаза, chunk = капсула, impasse-обработка = rollback (механический recovery) |
| **DSO / DSO-TRON / DSO_PLC / esp32** | детерминизм, минимизация jitter, тик, PLC-цикл | «тик = фаза» рождается здесь → L1/L5; RT-границы |

| **clefia / camellia / sint-crypto** | реализованные шифры + тест-векторы | валидация PC1 и будущих CA-раундов |
| **mandate / игровые моды** | детерминированный мир, сейвы | L5: сейв = фазовая точка, мир = ансамбль фаз |
| **sint-manifesto / AGENTS.md** | агент ≠ чат-бот; 7 когнитивных слоёв; провенанс | L5 автоинженер: шаг агента = фаза |
| **DSO-Refractor / dso-sdf / dso-sim / dso-runtime / dso-browser** | SDF, симуляция, наблюдаемость | ось B планирование; телеграф-наблюдаемость |

Два вывода из пазла:
1. **Почти всё уже построено** — не хватает связующего слоя (L3 decision-журнал,
   L4 капсулы, ось B) и дисциплины «всё есть фаза».
2. Некоторые системы вносят не код, а **направление**: RE = движение назад,
   SPARK = доказательство, CA/тройка = альтернативные ядра, KCC = когнитивный
   верх, PLC/RT = границы реального времени. PHASE их соединяет.

## 5. Жизненный цикл фазы (главный поток)

```
открыть фазу (mark / свежий кадр)
   │
   ▼
[вход на границе: данные/возмущения/входы — необратимо, один раз]
   │
   ▼
обратимое ядро (L0/L1): F — без ветвлений ИЛИ с decision-журналом (L3)
   │
   ▼
валидатор на границе (L3): инварианты ПОСЛЕ применения
   │
   ├─ ok ───► commit: запечатать hash-цепочкой → выход/капсула (L4)
   │
   └─ fail ─► rollback: F⁻¹ за O(шагов), 0 байт → повтор с другим кандидатом
```

Отказ — не исключение, а **ветка управления**: «fail = un-run». Перезапуск
процесса как стратегия восстановления заменяется откатом фазы.

## 7. Ограничения (чтобы не обещать)

- Не заменяет фон-неймана в сыром throughput и общей куче.
- Float, произвольный I/O, долгоживущие случайные жизни — вне парадигмы.
- Decision-журнал — это журнал; «zero logs» остаётся внутри фазы, на границе
  честно платим за решения.
- Криптографические утверждения PC1 — только демонстрация, не аудит.
- Неэрмитова «физика» — метафора для направленных планировщиков, не физика.
